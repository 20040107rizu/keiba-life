# 競馬育成＆馬券ゲーム 仕様書（v0.1）

友だち同士で遊ぶ、スマホのブラウザ向け競馬育成ゲーム。本格的に考えられるけど、サクサク進められる（放置ゲームにしない）ことを最重視する。

## 1. コンセプト
- 自分の厩舎で何頭も馬を育て、レースに出し、アプリ内ポイントで馬券を買う。
- 友だちの馬は常に「最新の状態」で自分のレースに出走してくる（オンライン）。
- ランキングで友だちの状況がひと目でわかる。
- お金は一切使わない。通貨はアプリ内ポイントのみ（初期 10,000pt 目安）。

## 2. 時間の進め方（最重要）
- ゲーム内時間は各プレイヤーが自分のペースで進める。リアル時間を待たせない。
- 1週単位で進む。週のトレーニングメニューを組んだら「1週進める」ボタンで即座に結果表示。
- 「次のレースまでスキップ」ボタンで数週間を一気に進められる。
- ゲーム内カレンダーは1年＝52週。年齢は年が変わると+1。

## 3. 厩舎
- 何頭も所有できる（上限はまず10頭、厩舎拡張で増やせる）。
- 馬の入手方法（すべて実装、段階的に）：
  1. セリ（市場）：ポイントで購入。能力の一部だけ見える。
  2. ガチャ：ポイントで引く。レア度あり。
  3. 配合：自分の牡馬と牝馬（引退馬含む）から子どもが生まれる。両親の能力・適性を受け継ぐ。
  4. 友だちとの売買・トレード：ポイントで売買、馬同士の交換。
- 実装優先度：セリ・ガチャ → 配合 → 売買・トレード。

## 4. 馬の能力
- 基礎能力：スピード、スタミナ、パワー、根性、賢さ（各 0〜1200 目安）
- 適性：距離（短距離・マイル・中距離・長距離）、馬場（芝・ダート）を S〜G で評価
- 脚質：逃げ・先行・差し・追込
- 調子：絶好調・好調・普通・不調・絶不調の5段階。週ごとに変動
- ケガ：トレーニング負荷が高いと確率で発生。休養週数が必要
- 疲労：きつい練習が続くと蓄積し、調子悪化・ケガ率上昇
- 年齢・性別（牡・牝・セン）、引退（任意、または一定年齢で）

## 5. トレーニング
- 週ごとにメニューを選ぶ（坂路、ウッドチップ、プール、併せ馬、ゲート練習、休養、レース前調整など）。
- メニューごとに伸びる能力・疲労量・ケガ率が違う。
- レース直前週に「調整」を入れると調子が上がりやすい。
- 結果は「1週進める」で即表示（能力の伸び、調子変化、ケガの有無）。

## 6. レース
- クラス：新馬戦・未勝利 → 1勝クラス → 2勝クラス → 3勝クラス → オープン・リステッド → G3 → G2 → G1
- 勝つほどクラスが上がり、上のレースほど賞金が大きい。
- 距離 1200〜3200m、芝・ダートの組み合わせ。
- 重賞は実在のレース名を使う（例：皐月賞、日本ダービー、菊花賞、天皇賞（春・秋）、宝塚記念、有馬記念、チャンピオンズカップなど。本物の距離・条件に合わせる）。3歳限定戦あり（三冠を目指せる）。
- ※実在レース名は友だち内での利用前提。レース名は設定ファイル1か所にまとめ、公開時に差し替えられるようにする。
- 出走馬：自分の馬＋友だちの馬（出走時点の最新データをサーバーから取得）＋足りない枠はCPU馬。
- レース結果は能力・適性・脚質と展開・調子・少しのランダムで決まる。
- レースはアニメーションで見られる（スキップ可）。

## 7. 馬券
- 券種：単勝、複勝、枠連、馬連、ワイド、馬単、三連複、三連単。
- オッズはパリミュチュエル方式（賭けられたポイントの合計から配当を決める）を基本に、CPUの仮想投票を混ぜて自然なオッズにする。
- 自分の馬が出ていないレースにも賭けられる。
- 調子やケガ明けなどの情報が予想のヒントになる。

## 8. オンライン・友だち
- アカウント登録とログイン（メールまたはGoogle）。
- フレンド追加（招待リンクやフレンドコード）。
- 友だちの馬・厩舎の最新状態が見られる。

## 9. ランキング（タブ切り替え）
- 総獲得賞金
- G1勝利数
- 最強馬（能力合計）
- 馬券の回収率
- 最高配当
- 今週の注目馬（最近大きく強くなった馬・連勝中の馬）

## 10. 画面
- ホーム（厩舎一覧・次のレース・ポイント）
- 馬の詳細（能力・適性・脚質・調子・ケガ）
- トレーニング（週メニュー＋1週進める／スキップ）
- レース一覧・出走登録
- 馬券購入
- レース観戦・結果
- セリ／ガチャ／配合／トレード
- ランキング
- フレンド

## 11. 技術
- スマホ縦画面に最適化したWebアプリ（PWA対応でホーム画面に追加できると良い）。
- Next.js + TypeScript + Tailwind CSS を想定。
- ログインとデータ保存は Supabase を想定。
- ゲームの計算ロジック（レース・トレーニング・オッズ）はUIと分けて、テストしやすくする。

## 12. 作る順番
1. 1人用：厩舎、馬の能力、週トレーニング＋スキップ、レース、全券種の馬券（データはまずローカル）
2. オンライン化：ログイン、フレンド、友だちの最新馬の出走、ランキング
3. 拡張：配合、売買・トレード、厩舎拡張
