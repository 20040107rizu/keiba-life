# three.js 中継カメラ

D はレース距離、S は `venueOf(race)` の当該馬場の直線長、R は補間位置からの先頭の残り距離です。表のFOVは35mm判の幅36mmから換算した基準値です。実効画角は各馬の投影位置から調整し、縦FOVは表示領域の比率で変換します。距離指定の切り替えは、短いレースで区間が重なる場合は順序を保って省略します。

東京の芝コースは2083.1m、内側のダートは1899mの近似形状です。他場も直線長・周回方向は競馬場データを使い、周回形状・勾配は演出用の近似です。馬体のギャロップには添付モデルのモーフを使い、低速でモーフの重みを下げます。

初期DPRは最大2。約45フレームの観測窓で24fps相当を継続して下回ると、上限を1.5、さらに1.25の順に下げます。第1段階からS4の全景帯と動的影を省き、楕円影の表示に切り替えます。端末の省データ設定やメモリ条件でも全景帯を省略します。実機目標はiPhone 12以降で30fpsです。

馬番は3D上の騎手の頭上から画面に投影し、小画面でも直径26 CSS pxを確保します。馬のルートを基準に固定し、重なった場合は奥のマーカーを半透明にします。設定の「馬の頭上に馬番を表示」で非表示にできます。

実写動画は発走前の2本です。ゴール後は同じ3Dレースのゴール時点を表示します。
