同梱の `public/models/Horse.glb` は、依頼者提供ファイルと three.js の配布ファイルがバイト単位で一致することを確認しました。実行時に馬の配色・スムーズ法線・縮尺・アニメーションの重みを調整します。この馬モデルとその改変には、表示・非営利・継承の条件が適用されます。アプリの **設定 → クレジット** からも参照できます。

場内音（歓声・ひづめ）はこのアプリのコードで生成したオリジナル音で、第三者の録音素材を同梱していません。実況は端末の Web Speech API が提供する音声を利用します。
