# 競馬ライフ

友だちと遊べる、育成と馬券のスマホ向け競馬ゲームです（PWA対応）。厩舎で何頭も馬を持ち、毎週の調教メニューを選び、「1週進める」「次のレースまでスキップ」で時間を進めます。セリ・ガチャ・配合で馬を迎え、新馬からG1までのレースに出走し、単勝〜三連単の馬券（パリミュチュエル方式のオッズ）を買えます。ランキングは6種類あります。

Firebase を設定すると、友だちと同じ「リーグ」に入って対戦できます。設定しなければ、今までどおりひとり用で遊べます。

詳しくは `docs/仕様書.md` と `docs/デザインガイド.md` を見てください。

## 担当
- UI・デザイン：Codex（ChatGPT）… `app/`
- ゲームロジック：Claude … `lib/`（`random.ts` 乱数 / `race-engine.ts` レース計算 / `odds.ts` オッズと払戻 / `game.ts` 成長・ケガ・進行 / `races.ts` レース設定 / `storage.ts` セーブ / `breeding.ts` 配合 / `ranking.ts` ランキング / `league.ts` リーグの出馬表・結果共有 / `online.ts` Firebase 通信）

## 起動方法
```
npm ci
npm run dev        # http://localhost:3000
npm run build && npm run start   # 本番ビルド
```
技術：Next.js（App Router）、TypeScript、Tailwind CSS、localStorage（`lib/storage.ts` で差し替え可能）、Firebase（任意）。

## 配合（ブリーディング）
- 引退した牝馬は「繁殖牝馬」（20歳まで）、引退した牡馬は自分の「種牡馬」になります。ゲームが用意する種牡馬（種付け料あり）も使えます。
- 厩舎 →「配合」タブで、繁殖牝馬と種牡馬を選んで種付けします。種付けシーズンは **第5〜24週**。
- 受胎から **48週** で翌年の春（第1〜20週）に仔馬が生まれ、**20週** の育成（育成牧場で自動的に成長。疲労・ケガなし）を経てデビューできます。週の進行（1週進める／スキップ）に組み込まれています。
  - ゲームでは当歳〜1歳の期間を省略し、仔馬は2歳として生まれます（2歳の夏〜秋に新馬戦、翌年に3歳クラシック）。
- 遺伝：成長限界は両親（成長限界6割＋引退時の能力4割）の平均を元に、全体平均への回帰とランダムな振れ幅で決まります。適性は両親の平均＋ブレ、脚質は父か母のどちらか（まれに隣の脚質）。
- インブリード（父方と母方に4代以内の共通の祖先）：血量＝Σ(1/2)^代数
  - 11〜20%（「奇跡の血量」3×4 など）：振れ幅が小さく、限界がやや伸びやすい。体質は少し弱め
  - 20〜30%（3×3 など）：当たれば大物・外れると虚弱。ケガしやすい
  - 30%以上（親子・きょうだい配合など）：能力が下がりやすく、とても体質が弱い（確認あり）
- 馬の詳細 →「血統表」で、父・母・祖父母・曾祖父母と、インブリードの祖先（金色の枠）を見られます。セリ・ガチャ・初期馬にも架空の血統がついています。
- 厩舎の上限（10頭）は現役馬と仔馬・受胎中の仔の数で数えます（引退馬・繁殖馬は数えません）。

## 友だちとのオンライン対戦（Firebase）
- ログインは **匿名ログイン＋ニックネーム**。リーグを作ると **6文字の招待コード** が出るので、友だちはそのコードで参加します。
- リーグのメンバーの「出走条件に合う馬」は、あなたのレースにも出走します（1レース最大5頭・1人2頭まで）。友だちの馬はレース画面を開いたときやレース直前に取り直すので、いつも最新の状態で走ります。馬券購入後も、友だちの馬のデータは最新に差し替えて走ります。
- 友だちの馬が5着以内に入ると、その賞金は持ち主に届きます（次にアプリを開いたときに自動で受け取り）。
- レース結果と馬券（的中・払戻）はリーグの「みんなのレース結果と馬券」に共有されます。
- ランキング（総獲得賞金・G1勝利数・最強馬・馬券回収率・最高配当・今週の注目馬）はリーグのメンバーで比べられます。
- セーブデータは端末とクラウドの両方に保存され、新しい方が使われます。通信できないときも端末の保存だけで遊べます。
- 匿名ログインのアカウントはブラウザに保存されます。ブラウザのデータを消すと別人扱いになるので注意してください。

### Firebase の準備手順（無料の Spark プランで動きます）
1. **プロジェクトを作る**
   [Firebase コンソール](https://console.firebase.google.com/) を開き、Google アカウントでログイン →「プロジェクトを追加」。名前は自由（例：keiba-life）。Google アナリティクスはオフで構いません。料金プランは Spark（無料）のままで OK です。
2. **Web アプリを登録して設定値を取る**
   プロジェクトの概要 → 「</>（ウェブ）」アイコン → アプリのニックネームを入れて登録（Firebase Hosting はチェック不要）。表示される `firebaseConfig` の値を控えます。
3. **匿名ログインを有効にする**
   左メニュー「構築 → Authentication」→「始める」→「Sign-in method」タブ →「匿名」を選んで「有効にする」→ 保存。
4. **Firestore を作る**
   「構築 → Firestore Database」→「データベースを作成」→ ロケーションは `asia-northeast1（東京）` など近い場所 →「本番環境モード」で作成。
5. **セキュリティルールを入れる**
   Firestore Database の「ルール」タブを開き、このリポジトリの `firestore.rules` の中身をすべて貼り付けて「公開」。
   （Firebase CLI を使う場合は `npx firebase-tools deploy --only firestore:rules --project あなたのプロジェクトID` でも反映できます）
6. **公開するドメインを許可する**
   Authentication →「設定」タブ →「承認済みドメイン」に、アプリを置くドメイン（例：`your-app.vercel.app`）を追加します。`localhost` は最初から入っています。
7. **環境変数を設定する**
   `.env.example` を `.env.local` にコピーし、手順2の値を入れます。
   ```
   NEXT_PUBLIC_FIREBASE_API_KEY=（apiKey）
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=（authDomain）
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=（projectId）
   NEXT_PUBLIC_FIREBASE_APP_ID=（appId）
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=（storageBucket・任意）
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=（messagingSenderId・任意）
   ```
   Vercel などに置く場合は、同じ名前の環境変数をホスティング側の設定画面に登録してから、もう一度ビルドしてください（`NEXT_PUBLIC_` の値はビルド時に埋め込まれます）。
8. `npm run dev` で起動 → ホームの「リーグ」→ ニックネームを入れて「はじめる」→ リーグを作って招待コードを友だちに送ります。

- 設定値（apiKey など）はブラウザに配られる公開値で、秘密の鍵ではありません。データの保護は `firestore.rules` で行っています（自分のセーブは本人だけ、リーグの中身はメンバーだけが読める、書けるのは自分の分だけ）。
- 必須の4項目のどれかが空なら、オンライン機能は読み込まれず、ひとり用モードになります。
- 無料枠の目安（Spark プラン）：Firestore は1日あたり読み取り5万回・書き込み2万回まで。友だち数人で遊ぶ分には十分です。

### 開発用：エミュレータで試す
Java が入っていれば、Firebase のアカウントなしで手元で試せます（`firebase.json` にエミュレータ設定があります）。
```
npx firebase-tools emulators:start --only auth,firestore --project demo-keiba
```
`.env.local` に `NEXT_PUBLIC_FIREBASE_PROJECT_ID=demo-keiba`、`NEXT_PUBLIC_FIREBASE_EMULATOR=true`、残りの必須項目にはダミー値（例：`fake`）を入れて `npm run dev` します。
